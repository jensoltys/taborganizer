# Contributing to Tab Organizer

Thanks for wanting to help.

## Report a bug or ask for a feature

Open an [issue](../../issues/new/choose) and pick the bug or feature form. Say what you expected, what happened, and the steps to get there.

Found a security problem? Don't open an issue. Follow [SECURITY.md](SECURITY.md) so it can be fixed before anyone else sees it.

## Pull requests

I'm not taking pull requests right now. You're welcome to fork Tab Organizer and change it however you like under the [MIT license](LICENSE).

## Run it and test it locally

The README's "Run your own copy" section has the setup steps. To run every test:

```bash
npm run setup
npm test
```

## Code of conduct

Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
