# Security

Found a security problem in Tab Organizer? Please email **hello@jenbuiltit.com** instead of opening a public issue, so it can be fixed before anyone else sees it.

Include what you found and the steps to reproduce it.

Each copy of Tab Organizer runs on its owner's own Cloudflare account, so a fix here reaches your copy only after you pull it and redeploy. Watch this repo (Watch > Custom > Security alerts) to hear about security fixes.
